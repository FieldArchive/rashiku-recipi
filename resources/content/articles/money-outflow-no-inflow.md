# お金を出すことはできるのに、入る流れが見えない時のレシピ

::core
お金を必要なところへ流せるようになったら、次は受け取る入口を育てる段階です。
入る回路は消えたわけではなく、少額の注文や臨時の収入、縁のつながりの中に小さく現れています。

焦って外に取りに行くのではなく、小さな流れに感謝し、縁を大切にしながら、自分の本流の入口を開いていきます。
::

::me
お金を損得ではなく、
必要に応じて使うことは練習したおかげで、
ずいぶん上手にできるようになったと思う。

使う時にも、変にモヤモヤせず、
わりと心から気持ちよく使うことができるようになって、
とても良い感じです。

ただ、その一方で、
入ってくる流れにはまだ乗れてなくて。

つまりいま、
出ていく一方な状態になってるの。

そこが不安で、
せっかく育った使い方の気持ちが揺らぎそうで怖いの。
::

もったいないとか節約しなきゃでモヤモヤ悩んでいたころから比べると、
お金に対する考え方がとても良くなってきましたね。

* 家を整える
* 身体をほぐす
* 資格取得のためにお金を払う
* 必要な支払いをする
* 家族や会社のためにお金を流す

といった、
**自分や身近な人への投資・支払いは**
**「無駄遣い」ではなく、必要な流れ**です。

私は浪費しているのではない。
必要なところにお金を流している。
ということにまず、信頼をおいてください。

お金が出ていく回路に怯えなくなったこと、
お金を怖がらなくなったことは、
お金への接し方として、とても健やかな変化です。

なので、そのせっかく育った使い方の気持ちは揺らいでほしくないですね。

::me
私もそう思う。

でも、入ってこないのよ。
流れてこないの。

何がいけないんだろう？
::

何がいけない、というより、
まだ「受け取る入口」が整っていないのだと思います。

お金は、
使えるようになっただけでは循環しません。

必要なところに流す回路と、
自分の価値に対して受け取る回路の
両方があって、はじめて循環します。

いま育ってきたのは、
出す回路です。

次に見るのは、
自分がどこで価値を出していて、
その価値にお金が入ってくる入口があるか、
ということです。

::me
自分がどこで価値を出しているか？

そんなこと考えたことなかった。
どういう風にしてそこを育てればいいの？
::

「入る回路を育てる身体感覚」を取り戻していきましょう。

具体的にはまず、
「お金を受け取るために何を売るか」
から考えないほうがいいです。

いきなり売るものを考えると、
ざっちーが入りやすくなります。

売れるかな。
高いと思われないかな。
ちゃんと価値があるのかな。
こんなことでお金をもらっていいのかな。

そういう声が出てきて、
受け取る入口を作る前に止まってしまうからです。

::me
自分が人に売れるものは何か、
って視点からしか考えたことがなかった。

まさに、
私がやっていること高いと思われないかな
って気持ちになりがちだった。

でも、お金を稼ぐって、
そういうもんなんじゃないの？
::

そう考えているということは、
お金を得ることに対して、
不必要な「不安」がつきまとっていますね。

入る側についてはまだ、

「収入が止まったらどうするの」
「減っていく一方では」
「私は受け取れているのか」

という不安がある。

いまそうやって不安になるのは、
お金が入る側の回路が収入一本に見えすぎているからです。
しかも今月その流れが急に細く見えている。

だから身体が「まずい、出ていくばかりだ」と反応している。

入る流れが見えない時、
そうやって無駄に焦りがちです。

::me
お金が収入よりも支出が多いわけなので、
無駄な焦りなのではなく、必要な焦りなのでは？
::

浪費癖があったり、
借金をかかえている状態でその流れだった場合は、
多少考えた方がいいですが、
それでも焦るのは「無駄」でしかありません。

焦ってお金が流れてくるならいくらでも焦っていいですが、
そういうことはないでしょう？

特に、
あなたの場合は、
収入があって、借金があるわけでもなく、
ただ、出る道がキレイに流れはじめたせいで、
入る道の細さが気になり始めた、という状態です。

その場合は、焦るのではなく、
徐々にでいいので、流れにのる練習をすべきなのです。

本当は、**入る回路は消えたわけではなく、まだ育ちきっていないだけ**なので。

::me
そういわれると、
ちょっと安心するね。

まあ、まだ全く入るあてはないけれど笑
::

気づいていないだけです。

例えば
* 誰かから臨時でお金をもらった
* 急に1件少額の注文がはいった

これらをお金の流れにカウントせずにいませんか？

あなたがまず最初に行うべき練習は、
これらの**少額・臨時の流れに対して全力で感謝をする**ことです。

::me
たしかに！

一昨日はある人から
予期していないお祝い金をもらった。

そしてついさきほど、
少額の発注があった。

これもお金の流れになるのか。
::

そうです。
あなたのなかで、きちんとお金の流れができはじめています。

これを
「たかが少額」とか「臨時でしかないし」
などと侮っていると、
せっかく来ているお金の流れに気づけません。

まずは全力で喜んで、
こういう流れを見逃さないようにするのです。

小さな流れをちゃんと受け取ると、
自分の中に
「あ、こういう形で入ってくることもあるんだ」
という感覚が育ちます。

そうすると、
お金の流れのほうも
「こういうのでいいのね」
とわかって、
少しずつ入口を広げてくれるようになります。

::me
わかった。
どんなことでも見逃さず、お金に感謝するようにする。

他にはなにか育てられる方法ある？
::

他に良質なお金の流れの作り方としては、
**お金に関係なく縁を大切にすること**です。

例えば、知り合いから便りがきた場合、
ご縁の回路を大切にし、連絡を返す、できれば会う約束まですることです。

それに対してお金が出ていくからとは考えない。
その点に関してはあなたはだいぶ上手になっているから大丈夫だとは思いますが。

そして、営業ではなく、
「私はこういう事業を始めています」と水路を通すようにするのです。

::me
お金につなげようとしないで会うってこと？
それでお金につながるの？
::

ここは抽象論をいってもわからないと思うので、
具体的に見ていきましょう。

会った時にいきなり
「買ってください」「依頼してください」「仕事ください」
とは言わないことです。

「最近こういうことをしています」
「こういう相談を受けることが増えています」
「こういう仕組みを整えているところです」
という、自分の現状を自然に話すのです。

もちろん、相手の話も同じように聞くことが大事です。

その縁の中で、
あらたなお金の出口が発生したとしても、
流れの一部として見てみるのです。

それができるようになると、
ますます入口が広がっていきます。

いまはまだ実感できなくても、
お金の流れにはそういうものがあるのだと
覚えておいてください。

::me
え、それじゃあ
お金が出ていく可能性まであるじゃない。

怖くて会えないよ。
::

そう思ってしまう時は、
まだお金を損得の目で見ている状態に戻っています。

お金の流れは、
焦ったり、不安に思ったり、怖がったりしても、
太くはなりません。

擬人化すると理解しやすいかと思うのであえて人っぽく言いますが、
そういう態度でいる人に対してはお金は逃げていきます。

怖がらず、楽しく使ってくれる人のもとにお金は寄ってくるのです。

縁があって会った人に、
自分の状況を話し、相手のことも聞き、
必要だったらお金を流す。

このことで、
会った相手の中に「この人は何をしている人か」が残り、
さらに「この人は私に対してこういうことをしてくれた」が残ります。

それはあなたが想像する以上に、
お金の流れを自然に加速させる装置になります。

わかりますか？

::me
うーん、
その人がお金をもらえて嬉しいとなる、かな？
::

それだけではなくなります。

あなたのお金がどんな額であろうと、
相手の側にあなたのお金が流れたことにより、
あなただけだったお金の流れが見えない形で増えたことになります。

どういうことかというと、
あなたの活動が、あなたの手を離れて宣伝されることがあるということです。
具体的に言うと、
相手が持っている人脈に対して、相手の善意で紹介がなされる可能性があるということです。

あなたが渡したお金は、実はお金ではないと考えるとわかりやすいです。

損得でしか考えていなかった頃だったら想像できなかったかとは思いますが、
お金の流れは、縁の流れでもあるのだと理解できるかと思います。

あなたはいままでそこまで縁を大切にする練習をできていなかったのではないですか？

お金の入口の細さは、縁の細さでもあります。

::me
痛いところついてくるね。

その通りだ。
いままでは縁を作るのが苦手で
人とのかかわりを避けていた。

それがいまのお金の細さになっているわけか。
::

そうなりますね。
だからこそいまその練習を始めるのはちょうど良い機会です。

少額でも、自分のところに流れてきた縁を感じながらちゃんと感謝して受け取る。
その回路を育てる練習をしていく必要がありますね。

入る回路は、いま静かに育っています。

焦って外に取りに行かず、
あなたの本流の入口を開けるようにするのです。

お金を受け取る回路を育てる練習と、
縁をつなげる練習を同時にする感じです。

::me
私の本流ってなに？

他の人にあって話したりして広がっていくお金の流れは支流ってこと？
::

そうです。

他の人から発生する支流もとても大事な流れですが、
あなたが育てるべきはあくまで本流。

本流とは、あなたそのものから生まれるお金の流れです。

まず見るのは、
あなたがすでに自然にやっていることです。

* 人に頼まれること。
* 人より深く考えてしまうこと。
* 放っておけずに整えてしまうこと。
* 時間を忘れて調べたり作ったりしてしまうこと。
* 誰かに説明すると喜ばれること。

そのあたりに、
すでに価値の芽があります。

それらを大切に育て、
その話を積極的に周りの人々に話すようにするのです。

それによって、
お金の本流も支流も太くなっていきます。

国や公共の補助事業に応募するのも縁と流れをひろげる
一つの大きなきっかけになります。

自分の求められている能力、喜ばれる力を紙に書き出す良い機会になります。
応募して採択され、「お金が入る未来」の入口を現実に開く。

そういった作業もしていくといいですね。


::point
## お金が入る流れが見えない時のレシピ
* 「入る回路を育てる身体感覚」を取り戻す
* 「お金を受け取るために何を売るか」から考えない
* 入る回路は消えたわけではなく、まだ育ちきっていないだけ
* お金に関係なく縁を大切にする
* 縁の中で、あらたなお金の出口が発生したら気持ちよく流す
* 関連がありそうな国や公共の補助事業に応募してみる
