# モヤモヤのせいで、次の一手を間違えそうな時のレシピ

::core
身体が疲れている時は、ざっちーが野放しになっていることに気づけなくなります。
余白を取り戻すという発想も持てないくらい疲れている時は、とにかく休むことです。

本来ならそこまでひどくなる前に、身体からSOSの声が出ています。

余白で満たそうとして声をすべて消してしまうと、ざっちーの声が大きくなり、身体からの声が聞こえなくなっていきます。
身体からの声は特別なものとして、余白で満たされた最中も聞いてあげてください。

身体の声が静かになるまで休むことで、次の一手を間違えにくくなります。
::

::me
昨日ね、全然嫌な日じゃなかったのに、
なーんがモヤモヤしつづけていたの。

だからか、他の人がやることにムカッとしがちだったし、
私が選んだ内容もイマイチ、シュッとしてなかった。

朝起きて今なら
ああ、あのルートを選ぶのが正解だったのになぁ
って思えるのに、
余計なざっちーが出たせいで、
より良い案を思い浮かべられなかった。
::

日頃は余白を満たすことができて、
意識もできているのに、
なんかおかしな、モヤモヤした気分でいっぱいになり、
結果的に良くないルートを選んでしまった。

そういう日だったんですね。


::me
そうなの。

例えば、歩こうと思っていたのに
バスで帰ろうって言われた時に、イラっとした。

結局バスで帰ったけれど、そうじゃなくて、
今思えば、
他の人と合流するのがベストルート
だったから、合流できるまで
カフェでゆっくりお茶でも飲んで座って
待っていれば休憩できて疲れも取れてたと思う。

「バスなんてお金もったいないじゃない
あなたの分は支払わないよ」
ってざっちーが出たし、
「カフェいったらお金かかるじゃない」
ってざっちーが出てた。

まだざっちー克服できていないよね。
これって。
::

そうですね。

いつもだったら意識して避けられていたざっちーの声に
もろに飲み込まれましたね。

ではここで質問です。
なぜ普段だったら振り払えたざっちーに飲み込まれたと思いますか？

::me
可能性としては、あれもやらなきゃ、
これも仕上げなきゃって時間にピリピリしてたのと、
つかれぎみだった。

そこに、他の人から予期せぬ提案をされて、
ムカッとしてしまった。
フォローもできてなかったな。

ああ、まだまだだった。
::

大丈夫です。

余白で満たされることの大切さと
ざっちーの退治の重要性に気づいたあとでも、
そう簡単に毎回完璧な対応はとれません。

そこを責めるより、
今回は何が余白を削っていたのか
を見たほうがよさそうです。

あなたの答えのなかに、
正解が潜んでいます。

**「疲れ」は余白をとばす大きな原因**なのです。

::me
疲れ？

確かに、ちょっと無茶しちゃってたし、
ずっと休まず動き回ってたな。

余白のおかげか、
最善ルートばかり思いつけてて、
つい、無理しすぎちゃっていたのか。

途中までは楽しかった。
で、ある時から
なんかモヤモヤして、
ああ、疲れてるなとは思い始めてた。

その時ちゃんと休むべきだったのか
::

そうです。

余白で満たされていると、
きちんと「そろそろ休まない？」と
身体が語りかけてくれます。

その声を無視して頑張り続けると、
身体の声はだんだん聞こえにくくなります。

そうなってしまうと、
あとは徐々にざっちーが幅を利かせて、
不安や意味のないモヤモヤを振りまき始めるのです。

::me
そうだったんだ。

じゃあ、ざっちーが出てくるようになったら
すでに手遅れだったってことか。

知らないうちに余白がとんでたんだね。

もっと早くにやすんでおけば、
次の一手を間違えることには
ならなかったってことか。
::

そうなりますね。

日々、余白を感じることができるようになってきたら、
次はぜひ、身体の声にも丁寧に耳を傾けるように
心がけてください。

あ、ちょっと息がしづらくなってるな
背中がかたまってる？
長時間座り過ぎたかも

という声はざっちーの声ではなく、
身体からの声です。

その声まで、
消してしまわないように注意しましょう。

一度聞き逃すと、
つぎはざっちーの声に紛れて
聞こえなくなっていきます。

::me
余白って、私の中では、
どんな頭のささやきも無視することだった。

何も考えない。
考えを消す。

そうやってざっちーを消してきた。

身体の声も、
同じ頭のささやきみたいに感じていたんだと思う。

だから、
「そろそろ休んだほうがいい」
という声まで、
聞かなかったことにしていたのかもしれない。
::

なるほど。
そこが今回の重要な分岐ですね。

ざっちーの声と、
身体の声は違います。

**ざっちーは余白を奪う声**ですが、
**身体の声は余白を守る声**です。

::me
そうだったんだ。
知らなかった。

気をつけて身体からの声を聞くようにするよ。

そろそろ休んだら？って
語りかけられたら、
いったいどのくらい休むのが正解なの？

元気なのでつい、
無理して頑張りたくなっちゃう。

そんな長時間休みたくないよ。
::

時間で決めようとしないほうがいいです。

**身体の声が聞こえているうちは、**
**まだ身体が何かを訴えている状態**です。

息が浅い。
背中が重い。
目が疲れている。
座りたい。
もう歩きたくない。

そういう声があるうちは、
まだ余白を取り戻す途中です。

**休み終わりの目安は、**
**身体の声が静かになること**です。

呼吸が自然になり、
急いで何かを決めなくてよくなり、
身体の違和感を探さなくてもよくなる。

そこまで戻ったら、
慌てて悪手を選んだり、
もっと良い手を見逃したりせず、
次の一手を間違えなくなります。

::point
## モヤモヤのせいで、次の一手を間違えないためのレシピ
* 「疲れ」は余白をとばす大きな原因だと知る
* ざっちーは余白を奪う声、身体の声は余白を守る声
* 疲れたと感じたら、何か選択をしようと思わないこと
* 身体の声が静かになるまで、最優先で休むこと
* 何も考えず、身体と呼吸に意識を向け余白を取り戻す
::
