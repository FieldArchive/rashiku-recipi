# 大切な人が雑に扱われて、自分まで反応しそうな時のレシピ

::core
大切な人が雑に扱われて傷ついていると、自分が直接されたわけではなくても、こちらのざっちーが強く反応することがあります。

その時に大事なのは、相手を助けるつもりでざっちーの連鎖を広げないことです。

大切な人が自分で受け止めて戻ってきた時は、その出来事を奪わず、安心だけを返して、自分のところで終わらせることが必要になります。
::

::

良くない状況なのは、あなたです。

::

それともあなたの義憤からですか？

自分が100％悪かったし。
って言われた。

はい。

いまのあなたは、
相手から直接ざっちーをぶつけられたわけではありません。

あなた自身の内側から、
急にざっちーが立ち上がったわけでもありません。

でも、ざっちーを受けて傷ついている大切な人から、
知らないうちにそのざっちーを連鎖で受け取ってしまった状態なのです。

::me
なにそれ、わかりにくい。

つまりは、私は知らないうちに、
大切な人が受けたざっちーを
もらい受けちゃっていたってこと？
::

そうなりますね。

しかも、今回は
頼まれてもいないのに勝手に心を寄せて
ざっちーの連鎖をうけ、それをふくらませてしまっています。

その人のために行動をしようとしたでしょう？

頼まれていないのにそれをするのは悪手です。
決して勝手な行動はしないようにしてください。

大切な人が自分で受け止めて戻ってきた時は、
その出来事を奪わず、
安心だけを返して、自分のところでざっちーを終わらせる必要があります。

::me
そういうものなのね。
私がさらにあれこれやっちゃうと、
出来事をうばったかたちになっちゃうんだ
::

はい。

自分が直接されたわけではないのに、
自分の中のざっちーが強く反応してしまう。

動いて確認したくなる。
ことを荒立てた相手に言い返したくなる。
でも、本人はそれを望んでいない。

受け取ってしまったざっちーはどうしたらいいのか。

あなたができる一番良い方法は、
**あなたでざっちーの連鎖を終わらせる**
です。

それができるのはかなりな余白上級者となりますが、
できないことではありません。

::me
ざっちーの連鎖を終わらせる？

むずかしそうだけれども、
ぜひできるようになりたい。

どうすればいいの？
::

まず、
大切な人の出来事と、
あなたのモヤモヤを分けることです。

大切な人は、
自分が悪かったと受け止めて、
自分からあなたに話してくれた。

その時点で、
その人はすでに出来事を自分の中で
処理し始めています。

そこにあなたが蒸し返してしまうと、
その人は再度考え直さなくてはいけなくなります。

最悪の場合、
トラウマ化して、嫌な過去になってしまい、
その中にあなたも含まれてしまいます。

::me
え。
私がトラウマの一部に？
やだやだ。

気をつけないと。
::

そうです。

だからまずやることは、
解決しに行くことではありません。

「話してくれてありがとう」

そう言って、
静かに受け止めて、
安心だけを返すことです。

その出来事の一部にならないように注意してください。

相手のために動くのではなく、
相手が戻ってこられる場所になる。

これが、
**あなたのところでざっちーの連鎖を終わらせる、**
ということです。

::me
むずかしいね。

聞く一方ってことね。
アドバイスも余計だね。

でも、それ、問題から逃げていることにはならない？
もっとちゃんと受け止めてあげるべきでは？
::

まだざっちーがいますね。

これはあなたの出来事でも、あなたの問題でもないのです。
あなたが考えれば考えるほど、誰のためにもなりません。

あなたができることは、
あなたのなかでざっちーを終わらせること。
相手がどんなにざっちーまみれになっていても、
余白で満たされた状態で接し、
相手が素に戻れる場所でいることです。

あなたまでモヤモヤしてしまっては、
相手はいつまでもモヤモヤから解放できません。

大切な人なほど、心を寄せてしまいがちで、
だからざっちーまで共有しがちです。

痛みに寄り添うことは優しさではありません。

そうではなく、
慣れないとむずかしいのですが、
あなたは余白でいてあげつづけることが、
結果的に大切な人本人に寄り添うことになるのです。


::point
## 大切な人が雑に扱われた時のレシピ
* その人がざっちーまみれになっていても、痛みに巻き込まれない
* その人自身にその出来事の消化を任せる
* 聞き役に徹し、自分のところでざっちーの連鎖を終わらせる
* あなたは余白のままで接し続ける
::
