# 「してあげたのに」と思ってしまう時のレシピ

::core
「してあげたのに」という気持ちは、相手の課題を自分事として引き受けた時に生まれやすくなります。

相手がどうしてほしいのかを聞き、具体的に頼まれた時だけ、自分に無理のない範囲で応じましょう。
::

::me
前に、相手を元気にしようとして、
かえって悪化させてしまったことがあったの。

いろいろ考えた末、
「相手を元気にしてあげよう」
と思ったこと自体が
そもそもよくなかったのではないか？
って思った。
::

そうです。

一番最初の段階でやめることを覚えましょう。
つよい形で、あなたの「規則」としてしまうのです。

つまり、
**不調な相手に、こちら発の「一緒に行う回復プラン」を提案しない。**

余白があっても、善意でも、「最善だ」と思っても止める。
自分の判断力ではなく、ルールで止めます。


::me
やっぱりそうだよね。

最初っからそう思わなければ、
よかったんだよね。

あんな誰も得しない
嫌な体験は二度としたくないのよ。

二度としないためには
規則化することだね？

具体的にはどうやるの？
::

とにかく、
**相手の課題を自分事にしないこと**です。
これにつきます。

あなたは頭の回転が速いところがあり、
つい「あ、こうやったら相手のためになるんじゃない？」
って先回りして提示しようとしますよね。

それが当たりな時は
お互いに気持ちが良いのですが、
はずれると、目もあてられない悲惨な結果になります。

今回のように、
お金も時間もかかり、気もつかって、
なおかつ、不機嫌になられた、なんて事態、
もう二度と体験したくないですよね。

それには、
心の底から
**相手の課題に首を突っ込まない**
を規則として刻み付けるのです。

::me
たとえ、
相手が困っていても、
苦しんでいても、
行き詰まっていても、
こちらから
アドバイスや提案してはいけないということ？
::

はい。

一見冷たいようですが、
そうではありません。

ポイントは、
「相手からそれを求められたか？」
です。

あなたが先回りをして、
機転を利かせて、
というところが落とし穴なのです。

万一、それで悲惨な目にあったとしても、
あなたが「自分で勝手に提案したんだし仕方ない」と思えればまだいいです。

でも、現実のあなたはかなり動揺して、ざっちーまみれになってしまいましたよね。

そうなるようなら、まだあなたはその段階には至れていません。
厳しい規則を作って、行動を止める必要があります。

::me
よかれとおもって提案するなら、
それで酷い目にあっても落ち込むなってことね。
それは難しいから、やめるよ。

段階を落としたとして、
いまの段階の私にできることはなに？
::

相手には「何か必要なことある？」とだけ聞く。
具体的に頼まれたことだけ、小さく手伝う。
頼まれなければ、回復は相手に任せ、自分は別に過ごす。

といったことです。

わかりますか？
どれも、相手が主体となっています。
相手がどうしてほしいのかを聞き、自分に無理のない範囲で応じる。

それなら、
少なくともこちらの予想だけで動くより、
嫌な流れになりにくくなります。

それ以上のアイデアは、
どんなに良く思えても実行しないでください。
相手が自分から求めた時にだけ動くのです。

それで、かなりのリスク回避ができます。

この規則で止められれば、
「してあげたのに」と思うところまで進まずに済みます。


::point
## 「してあげたのに」と思わないためのレシピ
* 相手の課題を自分事にしない
* 自分の予想だけで先回りして動かない
* 「何か必要なことある？」と聞き、相手を主体にする
* 具体的に頼まれたことだけ、自分に無理のない範囲で応じる
* どれほど良い案でも、相手から求められていなければ実行しない
::
