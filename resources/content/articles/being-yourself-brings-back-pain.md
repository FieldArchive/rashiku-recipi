# 自分らしくしようとすると、痛い思いがよみがえる時のレシピ

::me
自分らしくしようとすると、
前に痛い思いをした感じがよみがえって、
すぐ閉じたくなってしまう。

だからいつまでたっても狭いままで、
のびのびできない。
::

また同じ嫌な思い、失敗を繰り返しそうで、
自分らしさに自分でブレーキをかけてしまうのですね。

せっかくざっちーに反応しなくなり、
余白で満たされている状態でも、
前に傷ついた記憶が残っていると、
自分を出そうとした瞬間に、
身体が「そっちは危ない」と止めにくることがあります。

そして、本当は自分本来の姿ではない状態でも、
より安全な状態だと思い込んで、自分本来の状態に戻るのを拒否してしまうのです。

::me
え、危なくない場合でも、止めにくるわけ？
::

そうです。
そこが今回のレシピの大きなポイントです。

人は、一度痛い思いをすると、
必要以上に心を閉じてしまうことがあります。

例えば過去に水でおぼれた経験をしたことがある人は、
水の事故を経験したことがない人よりも、
はるかに水の扱いに慎重になり、
最悪の場合、水に近づけなくなります。

これは「トラウマ」と呼ばれています。

その怖がる仕組み自体は全く悪いことではないのですが、
必要以上に慎重になる、怖がり過ぎると、
内面の[ざっちー](/articles/what-is-zatchy)につながることが大いにあるのです。

::me
そうなると、
一度痛い思いをしたらもうどうしようもないの？

トラウマを治す方法はないの？
::

あります。

ただし、
過去の痛みを完全になかったことにするというより、
痛みがよみがえった時に、
そこから抜け出しやすくする方法です。

「いま」にあるようにするのです。

トラウマは過去の産物です。

いま本当に危ないわけではないのです。

もしも、いま危なかったら全力で逃げてください。
でも、トラウマ起因の現象の場合、
本当に危ないわけでもないのに危ないと頭と心が閉じているだけです。

その苦しみから抜け出す入口になる言葉は、
ひとこと「**いまにあれ**」です。

::me
いまにあれ？

そんな呪文で苦しみが解けるの？
::

長年固まっていた痛みから抜け出すのは、
すぐには無理なように思えるかもしれません。

でも実は、一度ほどける感覚がわかると、
「なんでこんなことに苦しんでいた？」と思うくらい
気分が軽くなり、苦しみが薄くなっていきます。

一度ほどける感覚がわかると、
前と同じ強さでは戻りにくくなるのです。

::me
どうしてそうなるの？
::

心や身体は、
過去に痛かった時の記憶をもとに、
楽なほう、より痛くなかったほうに寄るのです。
本来の姿であることは優先しません。
多少不格好でも変でも、楽に感じる状態を優先します。
そしてその状態を記憶し維持し続けます。

ただし、
いまのあなたはそれがおかしいと気づけるくらい、
ざっちーから逃れ、余白で満たされた状態で、
なおかつ自分らしさに気づき始めていますね。

そうなってくると、
不格好で変な自分に違和感を持ってしまうのです。
いくら楽でも「本来は自分はこうではなかったのでは？」と気づいてしまう。

でも、トラウマが解けていないので、
本来の自分に進もうとすると痛みがぶりかえす。
やっぱりやめておこうとなる。

そんな風に、モヤモヤしている状態だと思います。

**過去にある状態をほどいて、常にいまにある状態になれば、**
**過去の自分がほどけ、本来の自分になります。**

これは体感しないとわからないことなので、
ぜひ試してもらいたいですね。

そしてこのレシピ、もう一つ大きなポイントがあります。

**心の痛みだけではなく、**
**身体の痛みにも同じ見方ができるんです。**

レシピを最初から、
心ではなく、身体の痛みだと思って読み直してみてください。

自分らしさを自分本来の身体と読み替えて、トラウマをコリと読み替えるとわかりやすいかと思います。

::me
どういうこと？
::

身体中のコリ、
肩こり、目の疲れ、足や腰の痛みなど、
これは一度なったら、二度と解けないと考えていませんか？

プロの整体師にもんでもらえたらちょっとほぐれるけれど、
またすぐにもどっちゃう、みたいな意識ではないですか？

さきほど、
自分らしくしようとすると痛い思いがよみがえる時には、
「いまにあれ」で解けると言いましたね。

身体でコリがある部分も、同じように、
「いまにあれ」と意識を整えるとふっとほぐれていきます。

ただし、両方とも、
頭で考えるのではなく、
**本当にいまにある**必要があります。

いまにある状態で「その状態でそのトラウマ（コリ）があるのはおかしい」と気づくのです。

その違和感に気づき、いまに意識を整えた瞬間、
ふっとほぐれるのです。

どんな対人関係があったか、
どんな風にそのコリができたかなどといった情報は必要ありません。

むしろ、それを思い出している瞬間は過去にあります。

過去にある時はほぐれません。

もちろん、
深くつらい痛みや、生活に支障が出るような症状は、
専門家の力を借りるべき領域です。

ただ、
**自分の身体や心は自分が一番良く知っている**という意識も、
大切にしてほしいのです。

自分の心や身体は、
自分では整えられないものだと決めつけないでください。

気持ちを楽に、余白がある状態で、
ぜひこのレシピを試して、
痛みやコリがとれる瞬間を味わってみてください。

::point
* 自分らしさをさまたげるものは過去の痛みだと気づく
* いまにあることで痛みはほどける
* 余白で満たされた状態で、いまに意識を整える
* 心だけではなく、身体も同じ意識でほどける
::
