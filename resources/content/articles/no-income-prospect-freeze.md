# 自分の構築を進めたいのに、お金の不安で手が止まる時のレシピ

::core
お金の不安が強い時ほど、ざっちーは過去の別ルートや未来の結果を見せてきます。

でも、そこに行くほど、いまの具体から離れてしまいます。

ざっちーを弱める一番の方法は、いまに戻ること。

金額を見る。必要な分を移す。今日やる一つに戻る。

いまの具体に戻ることで、「まあやれる」が戻ってきます。
::


::me
いまは、自分の構築を最優先しなきゃいけない時期だと思っている。

自分の価値を形にしていきたい。

でも、その間にもお金は出ていく。すぐに収入になる見込みはない。

そう思うと、
「このままでいいの？」
「早く結果を出さないとまずいんじゃないの？」
ってざっちーの声に埋もれて、何も手がつかなくなる。
::

それはつらいですね。

具体的に、いま何が一番つらいですか？

::me
クレジットカードの支払いで
口座の残金が足りないから、
貯金を崩さないといけないこと。

いままではなんとかなっていたけれど、
こうやって具体的に目に見える形で減り始めると、
気持ちでは大丈夫って思っていたけれど、
想像以上に耐えられないと気づいた。
::

お金の見方を少し変える必要がありそうですね。

貯金は、ただ増やして守るためだけのものではなく、
**未来の自分を通すために、過去の自分が置いておいた力**なんです。

だから今、貯金を崩すのは、
**「失う」ではなくて、過去の自分から今の自分へ、力を移すこと。**
お金の場所が変わるだけだと、心から理解することが必要です。

::me
それは考えたことなかったかも。

ただ貯めないと、増やさないと、減らさないようにしないと
って思っていた。
死んだら使えないし、使うためにあるよね、たしかに。

お金を貯めるために他人の仕事に自分の時間を割くのは本末転倒で、
自分のやるべきことがわかったのなら、
そのために過去の自分が置いておいてくれたお金を使う
という発想をしないといけないのね。
::

そうです。

それで腑に落ちましたか？

::me
だいぶよくなったんだけどね、一点、まだそれだと解決しないことがあってね。

実際使うのが家族のものだったりするんだよね。
自分のやることだけに支払うなら納得いくんだけど、
水道料金とか家族の服代とか、食事代とか、マンション管理費とか、
そういうのに出ていくのも受け止められるように気持ちを高めたい。

そうしないと、家族と不和になりそうでこわい。
またケチな私にもどりそうでつらい。

入ってさえくれればこんな風に思わなくて済むのに。
::

それはこう見るのがいいかもしれませんね。

家族のために消えている
ではなくて、
**自分が壊れずに暮らす場を保つために流している。**

水道代、食事代、服代、管理費。
それは「他人に取られるお金」ではなくて、あなたが自分の構築を続けるための生活基盤です。
家族の暮らしが荒れると、あなたの余白も荒れる。
家の空気が悪くなると、自分の構築にも戻れなくなる。
だからこれは、家族に使っているお金
というより、**自分の場を守るお金**
だと考えてみるのです。

::me
なるほどね。

余白がなくならないようにすれば、
自然とケチにはならないし、
家族との気もよくなるし、自分の気もよくなる。

そうやって考えろってことね。

お金が減ると考えるのではなく、
**過去の自分が貯めたお金で、場と余白を買っている**んだと。

お金よりも気が大事なのは確かだわ。
不和になって離婚とかしたら、よっぽどお金なくなるからね。
::

そうです。

お金は、ただ減っているのではありません。

預金という形で置いてあった力が、
水道、食事、服、住まい、家の空気に変わっている。

**その場が守られるから、**
**あなたはまた自分の構築に戻れる。**

だからこれは、
自分を削る支出ではなく、自分が戻る場所を保つための支出です。

::me
だいぶ腑に落ちたよ。

実際に、引き落としに足りない分を、
預貯金から口座へ移してみた。

つらかったけれど、形が見えると、まあやれるとも思った。
::

これからも、何かをするにつけて、
そうやってざっちーは過去の違うルートを見せてきたり、
自分がダメなんじゃないかっていう証拠を、頭に描いてみせたりすることでしょう。

でも、それは現実ではありません。

結果を考えはじめると、
気持ちは未来に行ってしまいます。

まだ結果が出ていない現実から気持ちが浮いてしまい、
そこをざっちーにつかまるのです。

**いまにあるようにする**のです。

実際に口座にお金を移動した瞬間は「いま」にいたので、
そこまでざわつかなかったのです。

ざっちーに居座られないように、
**いまやっていることに集中する**。

「いま」に居続ける訓練をしてみてください。

そうすることで過去に戻されることも、
未来を不安に思うこともなくなっていきます。

自分の構築を遮るなにかがよぎったら、
すぐに、いま、手元にある一つのことに、
気持ちを戻すようにしてみましょう。


::point
## 自分の構築を進めたいのに、お金の不安で手が止まる時のレシピ

* 貯金は、過去の自分が未来の自分を通すために置いておいた力
* 貯金を崩すことは、失うことではなく、今の自分へ力を移すこと
* 家族や暮らしへの支出は、自分が戻れる場と余白を守る支出
* お金は消えたのではなく、水道、食事、住まい、家の空気に形を変えている
* 見えない不安の中にいる時ほど、ざっちーは大きくなる
* 金額と引き落とし日を見て、必要な分を移すと、「まあやれる」が戻りやすい
* ざっちーが過去や未来を見せてきたら、いま手元にある一つのことに戻る
::
