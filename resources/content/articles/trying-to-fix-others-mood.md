# 相手を元気にしようとして、かえって悪化させてしまった時のレシピ

::core
余白で満たされていても、相手に受け取る余白がなければ、こちらの元気さや明るさが負荷になることがあります。

相手が求めていない回復プランを進めず、相手の回復は相手に任せることが大切です。

行き場を失った自分のエネルギーは、相手に向けるのではなく、自分が本当にしたかったことに使いましょう。
::

::me
相手の体調や機嫌が悪そうで、
なんとか元気になってほしいと思った。

あれこれ気を配って、
ここ数日、
元気になれるように手を尽くしていた。

相手の不機嫌はおさまらず、
気づいたら私まで
大不機嫌になってしまった。

なんでこんな残念なことになった？
::

その数日間、
あなたは余白で満たされていましたか？

::me
うん。
余白で満たされていて、元気だった。

だから、
相手にもその元気をわけてあげようと
色々手を尽くしていたよ。
::

そこに原因がありますね。

あなたは余白で満たされていた。
だから相手にも分けようとした。

でも相手には、それを受け取る余白がなかったのです。

::me
え？

私の満ちた余白を、
相手にも分けようとしたことがいけなかった？
::

相手に受け取る余白がある時なら、
それは良いことです。

でも、相手が不調で、受け取る余白がない時は、
あなたの元気さや明るさが負荷になってしまうことがあります。

今回起きたのは、まさにそれです。

あなたの気づかいが悪かったのではなく、
相手に受け取る余白がないところへ、満ちた余白を渡そうとしてしまった。

だから相手は疲れ、
あなたも「こんなにしてあげたのに」と削られてしまったのです。

::me
うわー、
そうだったんだ。

確かに、私にも
[相手の明るさがきつくて、気持ちがねじれる](/articles/jealousy-toward-capable-people)
ことがあったので、
不調な時に相手の明るさを浴びると、
逆につらくなることはわかる。

どこで止まればよかったのかな？
::

止まる合図は、
**「相手を元気にする案」が浮かんだ時**です。

体調を気づかうことと、
相手を元気にしようと意気込むことは違います。

不調な相手に必要なのは、
元気にする行動ではなく、これ以上刺激を足さない行動であることがあります。

**相手が求めていない回復プランを、こちら主導で進めない。**

これをまず肝に銘じる必要があります。

::me
相手が求めていない回復プランを
こちら主導で進めない。

これ、その通りだよ。
これが全てだよね。

どうやったら立ち止まれる？
二度としたくない。
::

相手が自分から強く望んでいない限り、
**相手を外へ連れ出す回復プランは出さない、が正解**ではあります。

どうしてもあなたが思いついた回復プランを提案したい場合は、
「こういうのもあるけど、今は何もしないほうがいい？」
くらいに薄く出すことです。

そして相手が乗ってこなければ、そこで終わりにする。

あくまで**主役は相手**です。

::me
でも昨日はね、
ちゃんと聞いたんだよ。

「体調大丈夫ならここに行きませんか？」って。

相手もその時は大丈夫と思ったんだろうね。
でも結局、全然ダメだった。

そんな時はどうすればよかったの？
::

難しいのはそこです。

相手自身も、
その時点では自分の余白や体力を正確にわかっていないことがあります。

だから、相手が一度乗ってきたとしても、本当に最後まで大丈夫とは限りません。

だからこそ、
相手が自分から強く望んでいない限り、
**相手を外へ連れ出す回復プランは出さない、が正解**なのです。

::me
まだわからない。

具体的にどうすればいいの？
::

まず言えることは、
相手の問題と、あなたの問題を明確にわけることです。

相手の問題に対しては、
**相手の回復も、出来事も、問題も、こちらが奪わない。**

これをとにかく意識してください。

このことは今回だけではなく、様々な問題に当てはまります。
相手の問題は相手の問題であり、あなたの問題にしてはいけないのです。

::me
そうだ。

これ前にも似たことをやっていた。
[大切な人の課題を奪わないレシピ](/articles/reacting-to-loved-one-being-hurt)があったね。

今回も同じだ。

私はまだ、
**相手の課題を奪わないでいること**
ができていなかったんだ。

私が解決してあげよう、って考えていた。

なんでそう思っちゃうんだろう？
::

それは、
あなたにざっちーがなく、余白で満たされていたために、
今の自分なら相手も元気にできると思ってしまったからです。

境界線は超えられません。

どこまでいっても
あなたはあなた、相手は相手なのです。

あなたが相手のためにできるのは、
**安心を返すことと、必要なら小さく手伝うこと**です。

相手の課題を、相手のものとして尊重する。

それができないと、
優しさのつもりが介入になり、
気づかいのつもりが負荷になります。

::me
相手の問題に介入しない、か。

うーーん。
わかるんだけど。

それだとなんか
私の余った満たされた余白、
良いと思ったアイデアが消化されない。

発表できないモヤモヤ、
そういった発散されないものが
どこにも行き場がなくて破裂しそうになる…。

それはあらたなざっちーなのかな。
ざっちーっぽくないんだけどな。
::

さきほどまでは「相手の問題」でしたが、
それは「あなたの問題」ですね。

ここを明確に分けて考えてください。

あなたのモヤモヤ、それは、ざっちーではなく、
満ちた余白から生まれたエネルギーです。

* 動きたい
* 分けたい
* 一緒に楽しみたい

その気持ち自体は、悪いものではありません。

ただ、行き先を相手に限定すると、
受け取ってもらえなかった時にざっちーへ変わります。

消す必要はありません。

相手に押しつけず、**自分の楽しみに使えばいい**のです。

::me
満ちた余白から生まれたエネルギーを
自分の楽しみに使う？

例えばどうすればいいの？
::

相手のために使おうとしていたエネルギーを、
自分が本当にしたかったことへ向けてください。

* 相手がいるから遠慮していたこと
* 一人だからこそ楽しめること
* いつかやりたいと思いながら後回しにしていたこと

そういうことを、
いまこそ自分のためにやるのです。

相手に看病や介助が必要な状態でないかぎり、
相手の課題は相手に任せて、
あなたは思い切り、気兼ねなく、
あなたのやりたいことにエネルギーを注ぐのです。

普段からそういう時のためにやることリストを作ってもいいかもしれませんね。

「相手に自分のエネルギーを押しつけそうになった時にやることリスト」

相手を元気にしようとして、かえって悪化させそうになる前に、
次からは、すかさず、自分が楽しみ、整うために全エネルギーを使うのです。

そうすることで、自分も落ち着き、
相手に適度な距離感で接することができるようになり、
関係を悪化させにくくなります。

そういうエネルギーの使い方、距離感の保ち方を
徐々に覚えていきましょう。


::point
## 相手を元気にしようとして悪化させないためのレシピ
* 満ちた余白は、不調な相手に押しつけると負荷になる
* 「相手を元気にする案」が浮かんだ時が立ち止まる合図
* 相手が求めていない回復プランを、こちら主導で進めない
* 相手の回復を自分の仕事にせず、それぞれの余白を守る
* 行き場を失った自分のエネルギーは、自分が本当にしたかったことに使う
::
