# 自分のモヤモヤがきっかけで負の連鎖を広げたくない時のレシピ

::core
自分の中にモヤモヤがあるまま相手に接すると、責めるつもりがなくても、その揺れが相手に伝わってしまうことがあります。

一度相手のざっちーが立ち上がってしまうと、負の連鎖がはじまり、手がつけられなくなります。

そうなってしまう前に、どうしたらいいかに気づくためのレシピです。
::

やり方は
**自分の態度にモヤモヤが混じっていたと気づいて、**
**相手に非がないことをすぐ伝える**です。

一見簡単そうですが、
「余白がない瞬間に出してしまう自分の不用意な態度に気づく」という行為は
非常に高度な段階です。

しかも、その瞬間、
あなた自身がなにか不測の事態で慌てている最中なので、
そんな時に相手の気持ちを思いやれる行動に出るというのは
かなり余白上級者にならないと難しいといえます。

でもできないことではありません。

もしそれができれば、
相手は嫌な気持ちにならずに
ざっちーも立ち上がりません。

ただし、
相手のざっちーがすでに燃え広がり、
別の話題に飛び火し始めたあとでは、
こちらが入り込んで鎮めるのはかなり難しくなります。

このやり方が通用するのは
基本的にはその前の段階までだと思っていてください。

* あなたが不用意な態度で相手のざっちーを立ち上げてしまった

この一瞬にのみ、通用するやり方だと覚えておいてください。

そこを通り過ぎて、相手のざっちーを立ち上げっぱなしにして放置すると、
ざっちーはどんどん膨れ上がって、
最初の問題のモヤモヤを忘れてしまいます。

だから、その後であなたがいくら最初の問題についてフォローを入れたり
謝ってみたところで、
相手のざっちーはもうすでにあなたの他の欠点、
過去の問題点などを大量に材料にしてしまっているため、
「そんなことじゃ許せない」モードに入ってしまいます。

そこまでいったらあなたにできることはもう関わらない。
ざっちーに反応しない。
ほっておくしかない、です。

このやり方は
試さずに余白のままでいられて済むのが一番なのですが、
万一、一瞬相手にぶつけてしまった時には
非常に有効なので、逃げずに是非試してみてください。

初動が大事です。

それができると、
ざっちーの連鎖を最初の火種の段階で止められるようになります。

## 自分のモヤモヤから負の連鎖を広げないためのレシピ
* 何が起きても焦らず、慌てない
* 自分の心の揺れで相手のざっちーを立ち上げさせない
* モヤモヤをぶつけてしまったと気づいたら、すぐ流れを止める
* 責めているわけではないと、できるだけ早く伝える
