# 価値の芽を、お金の入口につなげたい時のレシピ

::core
自然にやっていることは、そのままではまだお金の入口にはなりません。

価値の芽をお金の入口につなげるには、自分の才能を見せるのではなく、相手の困りごとや願いに届く形へ整える必要があります。

それは、自分が余白で満たされた状態で、相手にも余白を作り、満たしてあげることに通じます。

相手が「これなら頼める」と感じられる入口を作ることで、お金の流れは少しずつ太くなっていきます。
::

::me
「お金の流れを太くしたいなら、
あなたがすでに自然にやっていることを見ること。
そこに価値の芽がある。」

[前回](/articles/money-outflow-no-inflow)、あなたはそう言ったよね。

わかった気でいたけれど、
実際にその価値の芽をどうやって
お金の入口につなげたらいいのかが、
まだ腑に落ちていなかったようで、
いつまでたっても太くする方法が見つけられなかった。

どうしたらいいのか、
もっとわかりやすく教えて。
::

そうですね。

前回の言い方だと、
「自然にやっていることを見れば、お金の入口が見つかる」
ように聞こえたかもしれません。

でも、正確には少し違います。

自然にやっていることは、
そのままではまだお金の入口にはなりません。

それはまだ、
あなたの中にある**価値の芽**です。

自然にできることを探すだけではなく、
それを**相手が頼める形**にする必要があるのです。

::me
相手が頼める形？
それ知りたい。

どうすれば頼める形になるの？
::

まず、**「私は何ができるか」から考えるのではなく、**
**「相手は何に困っているか」から見ます。**

お金の入口は、あなたの才能そのものに開くのではありません。

誰かの中に、困りごとや、不安や、満たしたい願いがある。

それを放っておくと重い。
でも、自分ではうまく整えられない。

そこに、あなたが自然にできることが重なった時、
お金の入口が開きます。

::me
相手の困りごとや願いを見るってこと？
::

はい。

多くの人は、
自分の中に困りごとや不安、満たしたい願いがあり、
「これなら軽くなる」「これなら整う」「これなら近づける」
と思えた時に、お金を払う理由が生まれます。

ポイントは、
相手の困りごとや満たしたい願いを見つけ、
それを**安心して頼める道**に変えることです。

::me
たしかに私も、
何かを買う時はそうかもしれない。

困ったな、
これを解決する良いものはないかな、
と思って探していることが多い。

あとは、
自分では無理なことを頼むね。
::

そうです。

自分でするのが好きな人でも、
全部を自分で整えられるわけではありません。

「これを使えば整う」「これを頼めば軽くなる」
「この人なら安心して頼めそう」
そう思えた時に、人は気持ちよくお金を払えます。

つまり、売る側がつくるべきなのは、
頼む前の不安がほどけて、
**「これならお願いしても大丈夫そう」**
と思える入口です。

::me
ごめん、まだ腑に落ちてない。

いままで、私はずっと、
この才能を伸ばしたら人の役に立てるかも、
この能力をもっと世の中の役に立たせたいって
願って頑張ってきたところがある。

だから、
才能に沿った仕事をお願いされると、
それを全力でやってきた。
それで評価もされていた。

ただ、定期的にお願いされるまでに至らない。
自分から売り込むのはうまくいかない。

そのやり方は違っていたってこと？
::

あなたがやってきたことは、どれも間違っていません。

ただ、それだけでは、
お金の流れは太くなりにくいのです。

なぜなら、相手から見ると、
「今回は助かった」「この人はよくやってくれた」
で終わってしまうことがあるからです。

継続的なお金の入口にするには、
その才能を、**相手が次も頼める形**にしておく必要があります。

才能を役立てることと、
お金の入口をつくることは、
似ているようで別の作業です。

::me
やっぱりまだ理解できてない。

これが理解できていないと、
新しく人に会ってもお金の入口につながらない気がする。
正直、混乱している。

腑に落ちてない。突破できてない。
::

混乱するのは自然です。

それは、いままでのあなたが、
**頼まれたらできる人**だったからです。

頼まれた時に力を発揮することはできていた。
でも、そのままだと、まだ頼んでいない人には届きにくいのです。

お金の入口を作るには、まだ頼んでいない人が、
**「あ、これは私が頼んでいいことなんだ」**
と気づける状態を作る必要があります。

たとえば、
「私は料理が得意です」
だけだと、相手はまだ頼めません。

でも、
* 平日夜に疲れて帰ってきた人向け
* 15分で食べられる作り置き惣菜
* 3日分
* 料金は500円×3日分で1,500円
* 苦手食材は事前に聞きます

まで見えると、
相手は **「あ、それなら私が頼んでいいやつだ」** とわかります。

ここで初めて入口になります。

一度頼んでもらい、気に入ってもらえたら、
また頼んでもらえる可能性が生まれます。

そうやって、お金の入口は徐々に太くなっていきます。

::me
さっきからおんなじことを何度も、
形を変えて言ってくれているみたいね。

つまり、
依頼が来るのを待つのではなく、
こちらから、こういうことができますよっていうのを整えろってこと？
::

かなり近いです。

ただし「こういうことができますよ」と言うだけでは、
まだお金の入口にはなりません。

それは単なる自己表現です。

お金の入口にするには、その表現を、
相手が自分の困りごとや願いと結びつけられる形にする必要があります。

つまり、**「私はこれができます」** ではなく、
**「こういうことで困っている時に、こういう形で頼めます」**
まで言葉にすることです。

::me
ああ、心当たりある。

私はいままで、
自分が学んだこと、
知っていることをいかに表現するか、
いかに自分を人に知ってもらうか、
自分の言いたいことをいかに人に伝え、
共感を得るか、に注力してばかりいた。

それだと単なる自己表現であって、
お金の入口としては細い表現だったってことか。
::

そうです。
わかってきましたね。

自己表現だけでは、
相手は「すごいですね」で終わってしまうのです。

でも、相手の中にある困りごとや願いとつながった時、
**「それ、お願いしたいです」** に変わります。

どうせ表現するなら、そこまで意識して表現するべき、ということです。

::me
自分を出すのではなく、
こんな困りごとに対して、
私はこんなことができますよ、
っていう書き方をしろってこと？
::

かなり近いですが、自分を出さないというのを、
自分を消すという意味で使ってほしくありません。

お金の入口を作るとは、
自分の価値を隠すことではありません。

**主役を「私の才能」ではなく「相手の困りごとや願い」にする**
ということです。

自分の価値を、相手の困りごとや願いに届く形で置き直すことです。

わかりますか？

::me
やっぱり何度も同じことを言ってくれているね。

いままでは、派遣とか履歴書ベースだったり、
懇親会などで人に会った時に、
「私はこんなことをしています」
って話すことが多かった。

でも、それが仕事と結びつくことはほとんどなかったのよ。

それは、「私はこんなことができますよ」
という話し方だったからなんだな。

つまり、これからは「それならお願いしたいです」
ってなる話し方や記事の書き方を
練習していく必要があるってことだね？
::

そうです。

お金の入口を太くするには、
単なる自己紹介、自己表現からもう一歩進めて、
**「こういうことで困っている時に、私をこう使えます」** まで見えるようにする必要があります。

目指すのは、すごそうに見せることではありません。

相手が **「あ、それならお願いしたいです」** と言える形まで、
言葉を整えることです。

::me
ようやく見えてきた。

その訓練って、
具体的には何をすればいいの？
::

まずは、自分の能力をそのまま表現するのをやめて、
**相手の困りごとや願いごとを見通す練習** をします。

自分を脇に置き、相手を主役に置く練習をすることで、
自分だけを見ている人ではなく、きちんと相手を見る人になれます。

たとえば、

「文章が書けます」ではなく、
**「言いたいことはあるのにまとまらない時に、伝わる形へ整理するお手伝いをします」**

「相談に乗れます」ではなく、
**「頭の中でぐるぐるしていることを、次に動ける形まで一緒に分けます」**

といった感じです。

この練習は、お金の入口を太くするだけでなく、
信頼関係を作ることにもつながります。

その積み重ねが、
結果的にファンやリピーターにつながっていきます。

人は、自分の困りごとや願いをちゃんと見てもらえると、安心します。

その安心があるから、「この人になら頼めるかもしれない」と思えるのです。

だから、相手の困りごとや願いを見通すようにしてください。

それは、相手の余白を作ってあげること、
相手を満たしてあげることにも通じます。

::me
そうか。

自分の余白が満たされていないと、
相手の余白まで意識を向けられない。

きちんとしたやりかたで
お金の入口を太くしようとするのは、
かなり高度なことなんだね。

ぜひ、そのやりかたでキレイにお金を循環させたいよ。
::

常に余白で満たされることに慣れてきたあなたなら、
そのステップに進むことは無理がないです。

ぜひ、多くの人がどんなことに困っているか、
何に満たされていないかを察知するようにして、
その願いに応えながら、
気持ちよくお金が流れていくのを実感してください。

その流れが通りはじめるまであと一歩です。

::point
## 価値の芽をお金の入口につなげるレシピ
* 自然にできることは、そのままではまだお金の入口ではない
* 見るべきなのは「私の才能」ではなく「相手の困りごとや願い」
* 相手が「これなら頼める」と感じられる形に整える
* 自己表現ではなく、相手がお願いしやすい言葉にする
* お金の入口を整えることは、相手の余白を作ることにもつながる
::
