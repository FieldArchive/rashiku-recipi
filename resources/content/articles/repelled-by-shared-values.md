# みんながありがたがる空気に引いてしまう時のレシピ

::me
高級な宝石や、自然のもの、スピリチュアルなものを
過剰にありがたがる人を見ると、
どうしても引いてしまう。

みんなが同じものを美しいとか、
ありがたいとか、感動するとか言っている空気に、
どうしても乗れない。
::

同じように感じることを求められているようで、
身体が引いてしまう。

そういう人たちの様子に引いてしまう感情は、
過去の痛みや、押しつけられた価値観への拒否感が
ぶり返して反応してしまっている状態ですね。

あきらかな[ざっちー反応](/articles/what-is-zatchy)です。

それに、その人たちの視野の浅さも目についていて、
ちょっと小馬鹿にする気持ちが渦巻いていませんか。

それには、
「自分は悪くない、相手が悪いんだ」という反発が含まれています。

それらのシチュエーションを目にした時、
この二つの異なる雑な想いがあなたの中で膨らんでしまうため、
近づきたくないと心が閉じて引いてしまうわけです。

::me
本来良いはずのものに対して
引いてしまうのはもったいないよね。

なんで素直に心を開けないんだろう？私。
::

心が傷ついた状態で、
同じ状況を見せつけられると、
思い出させないでくれ、という気持ちから
心を閉ざしてしまうのです。

ただ、
「なんでこうなっている？過去になにがあった？」
と詮索しすぎる必要はありません。
ざっちーに餌をあげているようなものです。

大事なのは、まず
その人たちと、そのもの自体を、
わけて見ることです。

::me
お点前の美しさは好きだけど、
お作法を監視される感じは苦手。

着物の造形は好きだけど、
着こなしを取り締まられる感じは気持ち悪い。

文化としては尊敬しているのに、
それを独占して取り締まっている
自称・門番みたいな人たちの圧力が無理なんだと思う。
::

たくさん出てきますね。

好きな気持ちと、
嫌いな気持ちがからみあっていて
かなり、こんがらがっています。

でも、整理してみると、
あなたが嫌っているのは、
茶道や着物、自然やスピリチュアルそのものではありません。

上から目線で自由を締め付ける空気感や、
過剰にありがたがる空気感を嫌っているのです。

本当は好きなものだったはずなのに、
それを取り巻く人たちによって
歪に押さえつけられてしまい、
好きな気持ちを諦めてしまったのかもしれません。

繰り返しますが、
ここで過去に何が起こったのかを掘りおこす必要はありません。

ただ、良いもの、好きだと思っていたものを
素直に感じてください。

まずは良いものと、それをありがたがる人を
別のものとして見られるようになることが、
心のコリをほどく第一歩です。

::me
宝石もスピリチュアルも、自然のものも、
茶道も、着物も、
私、本当は好きなんだな。

もっとちゃんと触れたいし、
もっと深く知りたいと思っている。

でも、
本当にちゃんとやっている人を見ると嫉妬するし、
浅い状態で注意してくる人を見ると、
心底軽蔑してしまう。

そのせいで、
好きな世界そのものに近づくのが
複雑で苦しくなっているのかもしれない。
::

嫉妬も軽蔑も、バッドエンドルートです。
思いつめず、余白を感じるようにしましょう。

もっとシンプルに「素直に好き」でいていいのです。

他の人が何といおうと、あなたが好きでいたらいい。

注意されても、
「私はこれが好きなんだ」と
心から思えるようになることです。

なぜそれができないかというと、
相手の反応に対して過剰に意識し、反発してしまうからです。

そのためには、
あなたが「いまにある」ことです。

始めは相手の空気をもろに受け止めてしまい、反応してしまうでしょうが、
いまにあることで、徐々に薄れていきます。

好きなものを好きなものとして受け取れるように、
心を整えるようにしてくださいね。

::point
* 良いものと、それをありがたがる人をわけて見る
* 人への反応で、好きなものまで拒絶しない
* 「私はこれが好きなんだ」と心から思う
* 相手の空気に反応せず、いまにある
::
