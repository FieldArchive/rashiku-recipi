# 過去といまのはざまで、物を手放せない時のレシピ

::core
余白で満たされることで執着がほどけ、物を手放せるようになっていきます。

過去から逃げずに向き合い、自分の思いを記すことで、ものをいまに引き上げることができます。

「過去に紐づいて残っているもの」を「いま残っているもの」に引き上げることで、何を遺し、何を手放すかが選びやすくなります。
::


::me
私は昔から物が捨てられない人でね。
それを捨てちゃったら
二度ともう手に入らないということを知り尽くしている。

物を遺すことには人一倍関心があるのよ。
でも、どうやって遺したらいいかがわからない。

何を遺して、何を遺さないか。
うまい捨て方、うまい遺し方。

これをあなたと対話して、突破したい。
::

これは重要なテーマですね。

「いまこの時」を生きようとすると、
一見、「過去に紐づいて残っているもの」は、
すべて捨てる対象になってしまいます。

逆に、
もう二度と手に入らないからと
大切にとっておこうとすると、
ものであふれかえることになります。

ひとつ質問をします。

あなたにとって、
その「過去に紐づいて残っているもの」は
なぜそんなに大事だと思うんですか？

::me
それは、
その時に発生したものは
捨ててしまったら二度と
同じものが手に入らないからだよ。

その気持ちが、
どうしても簡単に捨てる気になれない。
::

では、
さらに深堀りしてみます。

どういったものは簡単に捨てる気になれますか？

::me
うーん、

コンビニで買い物したレシートとか、
鼻をかんだティッシュとか
使い古して穴の開いたTシャツとかかな。
::

もし、レシートが思い入れのある商品を購入した
記念すべきレシートだったらどうですか？

穴の開いたTシャツが限定品だったら？

::me
うわ、
むずかしいこと言うね。

たしかに、それだと簡単には捨てられないかも…。
なんとかしてとっておこうとしてしまうな。
::

逆に、新品でも、
まったくいらないもらいものだったり、
趣味にあわない器だったり、
興味のないチラシだったりしたらどうですか？

::me
それならわりと簡単に捨てられてるかも。

ただ、子どもへの贈り物だったり、思い出の器とかになると、
一気に捨てにくくなるね。
::

つまり、
同じ「過去に紐づいて残っているもの」であっても、
あなたの思い出に紐づいているものは特に捨てにくい、ということです。

あなたは物が捨てられない人だと言っていましたが、
何も捨てられないわけではなく、
**思い出に紐づいているものが捨てられない**のです。

その感情をほどかないと、
適切にものを整えることはいつまでもできません。

厳しいことをいうようですが、
あなたが亡くなった後、
その「過去に紐づいて残っているもの」は
遺す価値があるものだと思いますか？

::me
厳しいことを言うね

他の人にとっては、
ほとんどは遺す価値はないものだと思うよ
::

ではなぜ捨てられないのでしょうか？

それは、
過去にとらわれている想い、
ざっちーがこびりついているものだからです。

そのものをそのまま持っておくことに
そこまで意味がない、
過去がいまを圧迫しているのだ
ということがわかれば、
余白を取り戻すために、
手放すことができるはずです。

::me
大量の過去に囲まれて、いまを見失うのはいやだな。

なんとかしたい。
どうやったら過去の圧迫から逃れられるの？
::

それには、一度そのものとちゃんと向き合って、
処遇を決めて、整えてあげることです。

過去のものをそのまま放置していることは
逃げていることと変わらないです。

どうしてそれをとっているのか、
きちんと1点1点見つめて、
捨てるか遺すかの判断をするのです。

そうすることで初めて、
「過去に紐づいて残っているもの」が
「いま残っているもの」になります。

ものはすべからく、
いまに引き上げてあげる必要があるのです。

::me
ああ、なるほど。
ちょっとわかった気がする。

過去のもの、ではなくて、
いま使えるもの、
いまいるものに変えてあげるのね？
::

そうです。

たとえ、穴の開いたTシャツであろうと、
限定品で大事だし、捨てたくないなと思えたら、
あなたにとってそれは過去のものではなく、
いま大切なものになります。

それは遺す価値のあるものです。

そうやって1点1点、
あなたの身の回りにあるものを
定期的に見つめ直してあげることで、
「過去に紐づいて残っているもの」はなくなります。

いらないものなのに手放せない、という感覚は徐々に薄れていくはずです。

::me
その「もう使えないけれど大切なもの」が
膨大な数だったらどうするの？
::

余白で満たされて、
いまを生きることができるようになってくると、
執着が消えるので、
そもそも遺したいものが減っていきます。

そうやって絞られた「遺したいもの」は、
つぎに、現物でとっておきたいものなのか、
文章や写真で記録する形がとれるものなのかを見ます。

**現物でとっておくものも含めて、**
**「過去に紐づいて残っているもの」はすべて、**
**写真やテキストで、**
**なぜこのものを遺したいと思っているのか、**
**自分の思いを記しておくことをおすすめします。**

自分があとから見て楽しめる形で遺すようにしてください。

過去ではなく、
いまと未来の自分のために情報を遺すのです。

写真や文章は紙の形で遺すと、またそれが新しい
「過去に紐づいて残っているもの」
になってしまいがちですので、
できるだけデジタルで管理することをおすすめします。

::me
過去から逃げずにきちんと向き合って、
ものをいまに引き上げることの意義はわかった。

過去の遺物として死蔵されるのではなく、
生きたものになるからね。

でも、それでもまだすべてとっておきたいと思ったら？
捨てたら二度と手に入らないのは変わらないんだし、
捨てられない気持ちも変わらないんじゃない？
::

試してみたらわかると思いますが、
執着がはずれて、いまにある状態で、
1点1点にきちんと向き合い、
「これは本当にいまの私に必要か？必要ならなぜ必要なのか？」
とメモに遺していくと、すべてをとっておこうとはならなくなります。

一度捨てることの怖さから解放されると、
とっておく不便さよりも、
解放される気持ちよさのほうがずっと良いと気づくのです。

ちょうど、身体のコリに似ています。
あまりに当たり前に過去から続いてきたコリも、
一度いまあるべき状態に気づくことで、
前に戻ろうとはしなくなります。

そうやって、
「過去に紐づいて残っているもの」を
きちんとタグ付けすることで、
過去を手放し、いまにもってくることができます。

そうすることで、あなたにとって、
何を遺して、何を遺さないかの基準が見えてくるのです。

一度その基準に慣れると、
次からは過去のものとして貯めずに
手に取った瞬間に要不要の判断ができるようになります。

ポイントは、
余白を満たすことです。
雑念を持たなくなることで
ものを過去の感情ではなく、
いまベースで見ることができるようになります。

そうすることで、
いまの自分にとって要るものか？いらないものか？を判断できます。

たとえば過去の子どもや家族の思い出などは、
現物をそのまま放置せずに写真やテキストでタグ付けしてあげることで
あとから一覧で見て楽しめるようになります。

そうやってものを整えてあげるのです。

いつか誰かがなんとかしてくれるだろう、と放置せず、
ものをいまに引き上げてあげてくださいね。


::point
## 物を手放せない時のレシピ
* 余白で満たされることで執着がほどけ、いらないものを手放せるようになる
* 過去から逃げずにきちんと向き合って、ものをいまに引き上げる
* 現物ではなく、写真やテキストで遺すことに慣れる
* なぜこのものを遺したいと思っているのか、自分の思いを記しておく
::
