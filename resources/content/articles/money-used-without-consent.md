# 自分のお金を納得いかない形で使われてモヤモヤする時のレシピ

::core
自分のお金を納得いかない形で使われたように感じると、少額でも強いモヤモヤが立ち上がることがあります。

このモヤモヤは、お金そのものだけでなく、自分の領域や境界線を雑に扱われたように感じることから起きています。

まずは、何に納得できなかったのかを見ていくための仮記事です。
::


::me
我ながら、
一瞬一瞬で余白を意識できるようになって、
相手のざっちーにも反応しにくくなってきたと思うんだけどね。

私のお金を、
私が納得していない形で雑に使われたなって場面では、
どうしようもなくモヤモヤするのよ。

考えないようにしよう、
考えないようにしようと思っても、
なんで私がこんな思いをしなきゃいけないの？って
なかなか心が晴れない。

なんとかしたい。
::

相手のざっちーに反応しなくなってきたり、
余白で満たされていっても、
反応してしまう事柄がある。

そういう時は、あなたのかなり深いところと
結びついた「根深型ざっちー」のせいです。

これは、
[自分の選択を後悔している時のレシピ](/articles/cannot-trust-my-choice)
で見た「後悔型ざっちー」とも少し似ています。

今回のお金のモヤモヤは、後悔型ざっちーと近いけれど少し違います。
後悔型は「自分の選択を選び直したい」。
今回のは「自分のお金を納得しない形で使われたことへの境界線ざっちー」です。




うん、そう見ていいと思います。

ただし「まだダメ」という意味ではなくて、かなり深い層が見えるところまで来た、という感じです。

お金のざっちーは強いです。
なぜなら、お金はただの数字ではなくて、

自分の自由
自分の安全
自分の労力
自分の境界線
自分が大事にしているもの
相手に雑に扱われたくない領域
に直結しているからです。

だから、余白があっても立ち上がりやすい。
しかも「少額だから気にしないでいい」と頭で思っても、ざっちーは金額だけを見ていない。

今回のチェリーの件で反応しているのは、たぶん、

私のお金を、私が納得していない形で使われた
しかも、それを大事にされなかった
そのうえ、私が注意する側に回らされそう

という複合ざっちーです。

かなり強力です。
でも、こうやって見つけられたなら、ほどけます。
後悔型ざっちーも、毒親ざっちーも、見つけて言語化したらかなりほどけました。今回も同じ方向でいけると思います。















::point
## 余白を取り戻すときのレシピ
* 「これで大丈夫、これでいいんだ」と心から思う
* 「何もしていないこと」と「自分の価値」を重ねない
* 無理に進まず、詰まりをゆるめる
* 少しでも気持ちが通るほうを選ぶ
::
