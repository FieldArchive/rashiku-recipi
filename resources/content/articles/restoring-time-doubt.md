# 整えることに時間を使ったのに、これでいいのかと思う時のレシピ

::me
この数日、どこにも行かずに
身体をほぐすことに集中してた。

ふと、何もしていないのと変わらない気がして、
なにかしなきゃってモヤモヤしてる。
::

まず最初に、
[ざっちー](/articles/what-is-zatchy)に反応していたわけでもなく、[余白](/articles/what-is-yohaku)もある中で、
自分が本当にやりたいことを思いつき、
「身体をほぐしたいな」と感じて、
それを実行できている。

これは、
かなり意識が進んだ段階にいるといえます。

ただ、あなた自身がまだ
「本当に自分のやりたいことをする」
という時間の使い方に慣れていない。

だから、その隙をついて、
「もっとなにか生産的なことしないと」という
ざっちー寄りな声がささやいて、
心がざわつくのです。

::me
え？

なにかしなきゃって思うことって、
ポジティブで前向きな発想だよね。

ざっちー寄りなの？
::

はい。

* 新しいか
* 役に立つか
* 意味があるか
* 前と違うか
* 得るものがあるか

これらは一見、よい判断基準に見えますが、
かなりざっちー寄りの判定基準なのです。

仕事や事業では必要な場面もあります。
でも、これを人生のすべての時間に持ち込むと、かなりざっちー化します。

この判断基準は、
本来、対象物を整えるための道具です。

文章を直す。
仕事の進め方を見直す。
部屋の配置を整える。
事業の仕組みを改善する。

そういう時には、
「役に立つか」「意味があるか」「前よりよくなっているか」
という判断は役に立ちます。

でも、その基準を
自分の存在そのものや、余白を満たす時間に向けると、
急に苦しくなります。

::me
自分の存在そのものや、
余白を満たす時間に向ける？
::

はい。

遊んでいる時に、
「これは新しいのか」

人と会っている時に、
「得るものはあるのか」

身体を休めている時に、
「意味はあるのか」

快楽や触れ合いの時に、
「前と違うのか」

ぼーっとしている時に、
「役に立っているのか」

こうなると、今そのものを味わえない。
身体はそこにあるのに、頭だけが評価者になってしまう。

言っていることがわかりますか？

::me
なんとなくわかる。

そこまで頭で評価しちゃうと、
本来いまを楽しみ余白で満たされることまで
無駄って判断にすりかわる可能性があるってことね。
::

そうなんです。

あなたが今回悩んでいることは、
まさに「あなたらしいこと＝無駄」にすりかえようとする
ざっちーの声に、心を揺さぶられている状態なのです。

その声に耳をかたむけず、
「これでいいんだ」とさらに一段つよく、
余白を意識するようにしてみてください。

::me
むずかしいよ。

だって、いままでずっと、
それらの判断基準がいいと思って生きてきたから。

その判断基準が正しいこともあるんでしょ？
違いがわからないよ。
::

対象物を整えるための道具は便利なため、
つい自分にも使ってしまい、区別できなくなってしまいます。

「これでいいのか？」と思った瞬間、
あなたの思考はいまにいません。
過去か未来に飛んでいます。
その瞬間、
ざっちー化した判断によって、身体が固まります。

「これでいいのか」「無駄じゃないか」「もっと別のことをすべきでは」と、いまを見失う。

こうなった状態での判断が心を迷わせるのです。

::me
ざっちー化した判断が
心を迷わせるというのはわかった。

ではどうすればいいの？
::

自分に使ってしまった場合に気づくヒントは、
「あなたがいまにあるか」です。

判断はせずに、
そのことそのものを味わうようにするのです。

遊んでいる時に、
「判断せずに遊ぶ」

人と会っている時に、
「判断せずに会う」

身体を休めている時に、
「判断せずに休む」

快楽や触れ合いの時に、
「判断せずに触れ合う」

ぼーっとしている時に、
「判断せずにぼーっとする」

もちろん、
自分の心が「これは危ない」とか「間違っている」というような危険を感じる場面では逃げてください。

そうではなく、
純粋に余白で満たされた状況の時、
ざっちーによる悪影響がない場合は、
判断はいったん横に置いて、
いまやっていることそのものを味わうことを心がけてください。

そうすることで、徐々に
「本当に自分のやりたいことをする」
という時間の使い方に慣れていきます。

::point
* 判断や評価は対象物を整えるための道具
* 余白がある状態で起きる「前向き顔のざっちー」に気づく
* 整える時間は、判断するより味わう
* 「本当に自分のやりたいことをする」ことに慣れる
::
