# 予期せぬことが重なって、余白が試される時のレシピ

::core
余白があっても、予期せぬ出来事が重なり、ざっちーが連鎖する日はあります。

そういう日は、想定外の事実に対して余白が乱れ、そのままの状態で人に接してしまいがちです。

余白が乱れた状態で他の人と接すると、相手のざっちーを不用意に掘り起こしてしまうことがあります。

想定外の事実は、事実のみを受け取ることで、シンプルに対処できるようになります。
::

まずはどんな予測不能な出来事が起きても、
余白を整え続ける訓練が必要だな。

ただ、今回のように、ダメな対応をしちゃって相手に移っちゃった後は、
一体どうやって相手のざっちーを整えてあげられるの？

それとも、人って他人のざっちーは整えられないのかな。
::

他人のざっちーを、
こちらが直接整えることはできません。

整えるかどうかは、
最終的にはその人の内側のことだからです。

ただし、
こちらができることはあります。

まず、
自分が相手のざっちーに反応しないこと。

そして、
自分の中に余白を取り戻して、
事実だけを静かに置き直すことです。

相手がざっちーを発動している時に、
こちらまでざっちーで返すと、
連鎖はさらに広がります。

でも、こちらがいまに戻り、
落ち着いた状態で事実だけを扱うと、
相手のざっちーに、新しい燃料を与えずに済みます。

相手を整えるというより、
相手のざっちーに燃料を与えない。

それが、こちらにできることです。

こちらが反応しなくても、
相手は別の話題を使ってでも
ざっちーをぶつけ返してくることがあります。

だから、
こちらができることは、
相手のざっちーを消すことではありません。

こちらができるのは、
それを受け取らず、
自分の中で再点火させず、
連鎖をこれ以上広げないことです。

相手のざっちーがくすぶることまで、

自分が燃料にならないことはできます。

自分の余白を乱さず、

どんなに余白で満たされた時を過ごしていても、

そうすれば、
事実は、必要以上に大きな問題としてふくらみにくくなります。

焦ったり、慌てたり、
悲観したり、後悔したりといった負の感情が入り込むと、
余計な時間がかかるうえに、
他の人にその感情を移してしまうことになりかねません。

もし他の人に移ると、ざっちーが連鎖して
さらに時間がとられて手間もとられて疲弊してしまいます。

だからこそ、
不測の事態が起きた最初の段階で、
まず余白を整えることが大事です。

::point
## 予期せぬことが重なるときのレシピ
* 余白がある状態でも、予期せぬ出来事が連続して起きる日がある
* 想定外の事実はすべて、事実のみを受け取り、ざっちーを入れ込まない
* 余白が乱れた状態で他の人と接すると、相手のざっちーを不用意に掘り起こしてしまうことがある
* ざっちーの連鎖は、最初に乱れた余白を整えないまま人に接することで広がりやすい
::
