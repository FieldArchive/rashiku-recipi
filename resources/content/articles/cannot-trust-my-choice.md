# 自分の選択を後悔している時のレシピ

::me
もう選んだはずなのに、
これでよかったのかが気になって仕方ない。

もっと安く買えたかも。
もっと合うものがあったかも。
実物を見たほうがよかったかも。

考えても答えは出ないのに、
ずっとモヤモヤしている。
::

選択したあとに、
自分の決定を信頼できなくなっているのですね。

これは、選んだものそのものの問題というより、
選んだあとに出てくる「本当にこれでよかったの？」という声に、
飲み込まれている状態です。

::me
そう。
選んだものが本当に悪いわけではないのに、
自分の選択をまったく信頼できていない。

しかも、使う相手がそれでいいって言っているのに、
買った私が「ほんとにこれでよかったの？」って
勝手にいつまでも悩んでいる。

実物を見たところで、
それはそれで高い買い物をしたかも、とか
もっと別の商品があったんじゃないか、とか
悩んだと思う。
::

何をしても悩むことになる可能性は高いですね。

いま、あなたのなかに余白は感じられますか？

自分の中のざっちーに反応している様子は感じ取れますか？

::me
余白でなんとかしようとしても、とれない。
ざっちーだとわかっていても、とれない。

きっと私にとって根深いざっちーなんだろうね。

これ、また同じようなことが起きると思う。
だから、ここで克服したい。
::

ここでほどけたら、かなり楽になりそうですね。

今回の件は、簡単に流せるざっちーではなく、
もう少し深く見たほうがよさそうです。

あなたはこの現象、何のせいだと思いますか？
そして、どんな状態で悩んでいて、どうしたいですか。

::me
たぶん、お金の問題もからんでるよね。
あと、複数の選択肢がある場合。
これが一番ってできない場合。
選択肢が一長一短だった時。
ずっと悩む。

時間ももったいないし、気分も晴れない。
これをなんとか止めたい。
::

いくつかの要素がからみ合って、
モヤモヤがほどけにくくなっているのですね。

なぜそこまで根深い状態になったと思いますか？
きっかけや原因は何か考えられますか。

::me
一番の原因は、
昨日買いに行く予定のお店に行ったらお休みだったことだと思う。

今日、朝急に思い立ってネットで子どもに見せて気に入ったものを買ったけれど、
実際は家族で一緒に土曜日に見に行って、そこで買いたいなとは思ってた。
昨日買えていれば何も考えずに済んだんだけれど、休みだったから。
全部の想いが崩れちゃった。

でも、そういうことってこれからもたくさんあるわけで。
例えば第一志望の場所に行けなくなった時の気持ちの切り替えみたいなものだよね。

一番良かったことが叶わなくなった時の、対処法が、私はできてない。
ずーっとあれこれ悩み続けてしまう。
一番よい選択肢はなに？って。

これって、私の長所でもあるけれど、深掘りしすぎて短所になってる。

昨日買えていれば一番良かったのに、
それがダメだったせいで計画が一気に崩れて、
なにをしてもダメかも、というルートに入っちゃった。

だから、どの選択をしても悩む結果になるのかも。

どうやったら、この沼から抜け出せる？
::

どの選択をしても悩んでいたと気づけたのは、
とても大事です。

つまり問題は、
選択肢の中に正解がなかったことではなく、
選んだあとに「これでよかった」と受け取れないことです。

これは、選択を間違えたから苦しいのではなく、
「本当はこうしたかった」という第一希望が残っているから苦しいのですね。

次善の選択をしたあとも、
叶わなかった願いが残っていて、
それが「これでよかったの？」と問い続けているのです。

第一希望が叶わなかった時点で、
その後の選択が全部「負け」に見えてしまう。

今回でいうと、

* お店で見て買う
* 気に入ったものを選ぶ
* 安く買う
* みんなで納得する
* すっきり買う

これが理想ルートだった。

でもお店が休みだった。
その瞬間に、理想ルートが崩れた。

そこから先は、どれを選んでも、

* でも本当はお店で買いたかった
* でも実物を見ていない
* でももっといいものがあったかも

になる。

今の選択が間違いなのではなく、
叶わなかった理想ルートをまだ惜しんでいるだけ。

ここを見抜かないと、
「後悔」という形で、ずーっとざっちーがあなたを痛め続けます。

::me
そう。
後悔だ。

次の選択肢しかないのに、
それを認められてない。

どうやっても、
昨日買うよりは遅いし、お店に行けてないし、安いかわからないし、
って後悔のタネをまき散らすから悩み続ける。

どうやったらとれるの？
ざっちーがわかって、余白で満たしているんだけど、
後悔はあるよ。

後悔って、他人の雑な反応とか自分の雑な反応とかよりも根深いのでは？

ああすればよかったって根深い。
::

まさにそこですね。

今回のモヤモヤは、
理想ルートはもう消えたのに、
心がまだ理想ルートを基準にしている状態です。

だから、次の選択肢が全部「劣った選択」に見える。

**後悔は、過去を選び直そうとするざっちー**です。

後悔が根深いのは、過去に戻って「なかったことにしたい」からです。
他人の反応や自分の反応より、時間そのものに逆らっているので、かなり強い。

ここまでくると、ざっちーはどのルートでも許さない可能性が高いです。

ざっちーに翻弄されていますね。

ネットを選べば「土曜日に行けばよかった」
土曜日に行けば「ネットで先に買えばよかった」
安いものを選べば「合わなかったかも」
良いものを選べば「高かったかも」

こういうやつです。

あなたは
**どの選択にも文句をつける声を、真面目に聞きすぎています**。

::me
なるほど。

じゃあ、真面目に聞かず、
言われたら言い返してみたらどうかな。

試してみる。

あれ、試そうと思ったら声がしなくなった。
なにも思い浮かばなくなったよ。
::

ざっちーは、正しい判断を教えてくれているのではなく、
どの選択にも文句をつけているだけだと気づくのは、
後悔から抜け出すよいきっかけになります。

これは「言い返す」というより、「見抜く」に近いです。
見抜かれたざっちーは、続けにくくなります。

後悔の声は、
より良い選択を教えてくれる声ではなく、
どの選択にも文句をつける声だった。

そう気づいたら、
その声を判断基準にしなくてよくなります。

::me
すごい効果かも。

余白しかなくなった。
反論するっていうのは、ざっちーにとって想定外なのかね。
黙っちゃった。
::

あんなに頭の中で騒いでいたのに、
いざ反論しようとしたら、
言い返す相手がいなくなっていた。

つまり、それは本当の検討ではなく、
ただのざっちーの声だったということです。

後悔の声は、
正しい判断を教えてくれる声ではありません。

**どの選択にも文句をつける声だと見抜くと、**
**その声はすっと消えます。**

::me
このタイプのざっちーは、
相手に雑な反応をされてイラっときたり、
モヤっとするのとは違うタイプだね。
::

違いますね。
かなりタイプが違います。

相手に雑な反応をされるタイプは、
外から刺激が来ます。

* 相手が雑に言った
* 相手が踏み込んできた
* 相手が失礼だった

それに対して、
自分のざっちーが反応する。

でも今回のタイプは、
外からの相手がいません。

自分の中で、
選択後に勝手に裁判が始まるタイプです。

* 本当にこれでよかったの？
* もっと安く買えたんじゃない？
* 別の選択肢があったんじゃない？
* なんであっちにしなかったの？

つまり、これは
**後悔型ざっちー**です。

特徴は、

* 終わった選択を蒸し返す
* どの選択にも文句をつける
* 正解探しのふりをする
* 「かも」を無限に出す
* 反論しようとすると消える
* 本当は検討ではなく、自己不信を燃やしている

相手への反応型ざっちーは、
外部刺激への反応。

今回の後悔型ざっちーは、
内部裁判の再生です。

::me
うん。

相手への反応には対処できるようになっていたのに、これには対処できなかった。

今回、また一つ、ざっちー攻略法を得られたので、
同じような場面がきたら使ってみるよ。

後悔型のざっちーには長年悩まされてきたので、
言い返すことですっと消えるとわかったのはありがたい。
::

そうですね。
ざっちーにもレベルがあります。

簡単に整えられるものから、根深いものまで。

その都度、正体を見抜いて、
ほどき方を探っていけばいいのです。


::point
## 後悔型ざっちーをほどくレシピ
* 後悔は、過去を選び直そうとするざっちー
* 後悔型ざっちーの声は、正しい判断を教えてくれる声ではない
* 後悔型ざっちーは、どの選択にも文句をつける
* 言い返そうとすれば、声が消える
* 消えないざっちーほど、正体を見抜く必要がある
::
