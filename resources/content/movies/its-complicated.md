# 恋するベーカリー（2026/5/8）

::me
この映画、前に観たことがあったの。
また観たくなって探して観た。
::

どんなところが印象的で、
また観たくなったんですか？

::me
この頃のメリル・ストリープ主演の作品って魅力的な作品が多くて、
それで観た作品の一つ。

オシャレで素敵な映画だったなって印象だったので、
もう一回観てみたくなった。

やっぱりオシャレで、とにかく家の設えが素敵すぎ。
家を増築しようっていうのが映画の一つの軸なんだけど、
この主人公は、家へのこだわり含めて、
とてもセンスあるなと思った。

なにより料理上手で。

私、アリス・ウォータースがすごく好きなのだけど、
まさにそんな主人公で観ていてわくわくした。

**家がキレイで料理が上手って最高に素敵**だなって、
もう一回観てあらためて思った。

私もそうなりたいんだなって。
::

なるほど。
ほかにこの映画を観て感じたことはありますか？

::me
事業をおこして成功している女性もかっこよくて好き。

**きらきらしている女性は年を重ねても美しい**
っていう見本みたいな映画だなと思ったよ。

別れた旦那がまた関係をもちたくなるなんて、
最高の賛辞じゃない。

まあ、そのせいで今回はごちゃごちゃしたわけなんだけど。

邦題は『恋するベーカリー』だけど、
原題の It's Complicated のほうが、
内容に沿ってるなと感じた。

単に「恋する」だけじゃ浅い。
もっと深くて複雑だったよ。
::

どんなところが、
It's Complicated だと感じましたか？

::me
まず離婚した理由がわからないくらい合うのに、
なんで別れた？っていう点。

そして、やっぱりどう考えてもこの2人お似合いなのに、
なんで一緒になれない？
と思いながら観ていた。

でも、確かにもう一緒にはなれない。
複雑だなぁって思ったよ。
::

最初の結婚は、どうしてうまくいかなかったと思いますか？
なぜそんなにお似合いの二人が別れたんでしょう。

::me
途中で旦那さんが
「Agness started out really looking up to me.」
って言っていた。
たぶんそこじゃないかな。

女性側が事業でもなんでも、
なにか自分を貫いたことをやろうとすると、
どうしても旦那よりも強くなる場面、
旦那がおざなりになる場面、
強く前に出て、主導権を持つ場面が出てくるんだと思う。

それに旦那側が耐えられなかったんだろうなって思った。
::

なるほど、
旦那が自分の扱われ方に耐えられなくなって、
他の女性が頼って尊敬してくれる様子に
心を動かされてしまったということですね。

::me
うん。

二人で語り合う場面で、主人公が
「Back when we broke up I knew it wasn't all your fault.
I think in some way, I gave up on us. 」って言っているの。

主人公も気づいていたんだと思う。

自分の事業や子育てやその他のことにかまけて、
旦那を思いやることをあきらめてしまったんじゃないかな。

あとまわしになってしまった。

それで、旦那は居場所、拠り所がなくなってしまった。
::

それが二人がわかれる主な原因だったと。

::me
そう。

だから、途中で旦那が
「All the things that tore us apart aren't issues anymore.」
って言ってるの。

再婚相手の女性が原因じゃないって暗に言ってる。

お互い仕事中毒で余裕がなくすれ違いがあって別れたけれど、
いまは全部一段落して何の障害もないって。
::

彼らを引き裂いたすべての原因がなくなったのに、
結局なんでうまくいかなかったと思いますか？

::me
そりゃあ、
いまの奥さんと正式に離婚しなかったからでしょ。

そのせいで主人公とのデートをすっぽかしたんだし。

そういった**小さな疑念が積み重なって**
**それが解消できないくらい大きくなったのが**
**離婚の一番の原因**だったんだよ。
それを10年でようやく主人公は解放できた。

なのに、旦那はまた同じミスを犯して、
主人公も同じわだかまりをかかえてしまった。

それに気づいたんだね。
この人とはダメだって。
::

いまの奥さんと正式に離婚していたら違っていたでしょうか？

::me
「Probably would've been better if you hadn't been married.」
って言っているくらいだから、独身だったらまた違っていたかもしれない。

でも、たぶんだけど、たとえ奥さんと別れたからって、
この二人ではずっとバッドエンドループになるんじゃないかな。

気づかず振り回す旦那と、それに振り回される主人公。

もし、旦那が独身になり、
主人公が内外のざっちーに反応しなくなれれば、違うエンドになるのかもね。

でも、この物語はそれを選ばなかった。
別々の道に行く感じの終わり方だったね。
::

あの映画の終わり方をどう思いますか？

::me
わからないな。

あたらしい建築家さんは
まったく違うタイプで、どうなるかはわからない。

でも、
ちょっと悪い見方をするとね、
主人公が今度は建築家さんを振り回す側になるんじゃない？って思った。

実際、嘘ついて誘われたデート断っているし。
旦那に断れって言われたから。

一応区切りつけたけれど、
ちょっと火種があるままって気がしたよ。
::

また旦那が振り回して、
主人公が振り回されて、
さらに建築家さんも振り回されると？

::me
うん。

むずかしいけれど、
旦那さんというざっちーに反応しつづける癖が
とれないならそうなるんじゃないかな。

個人的には、旦那がせっかく別れるっていってきたんだから、
しっかりと離婚してもらってから、
寄りをもどしたらよかったのになとは思ったよ。

あの終わり方だと、まだ終わってない。
建築家さんが最後に言ってたけれど、解決してないもんね。

そんな状態でなあなあに建築家さんと恋に落ちて、
うまくいくのかなぁ？とは思った。
::

あなたは終わってないと読んだんですね。

そうなると他の人が入ってきて、
さらに「It's Complicated」になりそうですね。

::me
ただ、
あの主人公、
心から打ち解けて語り合える仲間がいるでしょ。
それに、信頼できる精神科医もいる。

さらには自分の気持ちを切り替える術ももっていたし、
事業もうまく軌道にのってる。

だから、複雑でもなんの心配もないと思うわ。
::

そうですね。

面白いのが、
「罪悪感と恐怖心がなくなれば楽に進めると思う」っていう、
まさにざっちーまみれになっている悩める主人公に、
精神科医が
「I wouldn't resist lookin at this. Let go, Jane. It can't hurt.」
と言っているシーン。
気持ちを無理に避けず、進んでごらん。
試してみても、悪いことにはならないよって後押ししています。

たぶん、最後は自分で解決するってわかっていたんだと思いますね。

そのくらい、苦しんだ10年で自己分析が一人でできるくらい強くなっていたんだと思います。

つらいことがあっても、
信頼できる仲間と笑いあえ、子どもとわかりあえ、
人生を楽しみつくしていれば、
**複雑なことは複雑なままでも、**
**十分に豊かで幸せな人生が過ごせる**ということですね。


::point

* 暮らしに美意識がある人はステキ
* 心の弱さで閉じず、乗り越えることで新たな自分になれる
* 心から笑い語り合える仲間って大事
* 自分で自分をご機嫌に戻すすべをもとう
