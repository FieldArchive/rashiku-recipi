# プラダを着た悪魔（2026/5/7）

::me
この映画、前に観たことがある。

前回は、
「最初ダサい女の子が
自分の努力でどんどんキレイになる」
っていう印象しかなかった。
そして「最後は自立して巣立っていく」
みたいなラストだと思っていた。

普通に観ているとたぶんそうなっちゃうと思う。
::

具体的に、以前はどんな映画だと感じたのでしょうか？

::me
この映画、つい目がいきがちなのが、
「パワハラにめげず頑張ることで仕事の面白さに目覚めていく」
「ファッションであか抜けて自信がみなぎっていく」
「がむしゃらに頑張ると道はひらける」
みたいなところだと思うんだよね。

でもそれだけじゃ浅いと感じたよ。
今回は、そうじゃないところがやたら目についた。
::

たとえばどんなことでしょうか？

余白がある状態で同じ映画を観た時、
どんなところが以前と違ってみえましたか？

::me
一番感じたのが、
夢をかなえるのは1人じゃできなかったってこと。

自分の努力というよりも、
**周りを味方にして協力を得て成長していた**
って気づいた。

あと、自立して巣立つというよりも、
**友人の忠告などがじわじわと効いて、**
**おかげで最後に目が覚めた、**
**間違いに気づいた**っていう感じだった。

対人がキーになっている物語だなって。
::

なるほど。
一人で努力して達成したのではなく、
周りの人の助けがあったおかげだったことが見えてきたわけですね。

その見方で見ると、
最初のアンディはどう見えましたか？

::me
最初のアンディは、
編集部の人たちを少し馬鹿にして、
私はあの人たちとは違う、
私はあんな世界には染まらない、
と思っていたよね。

それってざっちーに反応しちゃってる。

だから、
周りが「自分の事をわかってくれない敵」
みたいに見えてたと思う。

最初は1人で頑張ってた。

でもある出来事をきっかけに、
人を頼って、
自分を開放することができるようになったよね。
::

そうですね。

自分を開放して人を頼るようになり、
ざっちーに反応しなくなってからは、
どんどん成果をあげていってた。

ただ、それだけではハッピーエンドにはなっていませんでしたね。

::me
意固地だった自分らしさをほどいて、
周りの人の助けを借りるようになって、
仕事では成功していくのよね。

でも今度は、
強い影響力のある人のもとで、
外側の世界に寄りすぎてしまう。

最初は固めすぎていた自分らしさをほどいたのに、
今度はほどきすぎて、
自分の中心まで見失いかけた感じ。

成功しても、ハッピーエンドとはいえないね。
::

外側の世界に寄りすぎたために
友達や恋人や夢など本当に大切にしていたものまで
手放しかけてしまったといえますね。

その状態からどうやって
バッドエンドではない状態、
つまり、自分の夢や大切なものを取り戻すまでもっていけたと思いますか？

::me
自分らしさを見失っていたことに気づいたからじゃないかな。
これは私じゃないって気づけた。

気づけた瞬間に魔法がとけたように
携帯を捨てて、その場を離れたよね。

そこからは、自分を保ったまま夢に向かって突き進めた。

まさに、
**見失った自分らしさを取り戻すまでの物語**だったんだと思う。
::

なるほど。

自分らしさを取り戻す物語として観ると、
かなり見え方が変わりますね。

他にも、観ていて心に残ったことはありますか？

::me
最初に、
ざっちーに反応しまくっていた「自分らしさ」に比べて、
すごく**周りに共感される「自分らしさ」に変貌をとげた**なって思った。

人生を切り開くには、
一生懸命になることももちろんだけれども、
人懐っこくあるべきだなって思った。

自分一人じゃなにも進まない、
味方が増えていくにしたがって良い展開になっていく。

これって映画特有のことなのかな？
::

映画は脚色が多いですが、
ざっちーに反応していた人が余白を取り戻していくと、
周りの人が敵ではなくなっていく、ということは現実にも十分ありえます。

夢を実現するためには、行動も大事ですが、
それ以上に、**自分らしさをつらぬきつつ、**
**周りが味方になってくれることが大事**だと
この映画は教えてくれているのかもしれません。


::point
【夢を手に入れるには】
* 自分を見てくれる友達を持つこと
* 自分でできることに全力で尽くすこと
* 人懐っこくあること
* 「自分らしさ」をはき違えないこと
::
