# テレメンタリーPlus「異才と呼ばれて」（2026/5/10）

::core
高い理想と善意から立ち上がったプロジェクトでも、関係する人たちの内側が整っていなければ、ざっちー同士がぶつかり合い、やがてバッドエンドルートに入っていきます。

才能を持つ子どもを「伸ばす」「社会につなげる」という名目で、大人が本人の地雷を踏んでしまう。
その結果、好きだったものや才能そのものが、痛みの記憶と結びついてしまうことがある。

才能は、他人が無理に伸ばすものではなく、本人が安心できる余白の中で伸びていくものです。

この記事では、才能を伸ばす前に、まず壊さないこと。
そして、好きなものや自分らしさで余白を満たすことの大切さを見ていきます。
::


::me
たまたま見たドキュメンタリーが、
想像以上に心に残った。

忘れてしまいそうなので、
ここで対話して、思いを整理しておきたい。
::

2014年に立ち上がった、
目立った能力を持ちながら、学校になじめない
子どもたちの才能を伸ばそうとした「ロケット」というプロジェクト。

この番組は、
そのプロジェクトに選ばれた
子どもたちの当時の様子と、その10年後を追ったものですね。

見ていて、最初に何を感じましたか？

::me
最初にこのプロジェクトの趣旨を観た時に、
この集まりは危ないなと思った。

選民意識が芽生えちゃって、
自分はすごいんだ、他の奴らはダメなんだって
見下す人たちを生み出すんじゃないかって思ったの。

その手の話の流れは嫌な感じがしたので
すぐにチャンネルを変えようかと思ったんだけど、
その後を見せてくれるというので興味があって
そのまま見続けた。

でね、番組見ていたらむしろ逆だった。
::

確かに、選ばれた子は、
「君はすごいんだよ」「他の子とは違うんだよ」って
言われているようなものですからね。

気をつけないと勘違いしてしまう状況ですね。

実際はどう逆だったんですか？

::me
いまのお前のままじゃダメだ、
もっと突き抜けてみせろ、
って煽るようなことしていたのよ。

そうすることで、
閉じこもった殻をやぶったり、
苦手なことを克服できると思ったのかなぁ？

なんで子どもたちに対して、あんなやり方していたんだろう？
::

おそらく、プロジェクト側は、
才能そのものだけでなく、
社会や現実と接続する力も育てようとしていたのではないでしょうか。

才能を社会の中で生かすには、
才能以外の経験も必要だと思っていた。

だから、
農業や馬の世話のような、
思い通りにならないもの、身体を使うもの、
他者や環境に合わせるものに触れさせた。

本人の世界を広げ、
社会とつながる力をつけさせたかったのかもしれないですね。

::me
私はそれでひどい目にあった側なので、
あのやり方がいかに問題があるか、よーーーくわかる。

見てて痛々しかったし、
実際、その子どもたちが大人になってからを追った
インタビューでも、
あのやり方で傷ついたって人が何人かいた。

そりゃあそうでしょう。
あのやり方を平気でやっている様子に、私は一番びっくりした。

どう考えても、せっかくの才能を潰すよねって。

なんでそこがわからなかったんだろう？
::

おそらく、
**人は、自分が踏まずに済んだ地雷は、そこに地雷があるとわからないから**
です。

どういう意味かというと、
できる側の人にとって、それをやってみることは、
少し勇気を出す程度のことに見える。

でも、できない側の人にとっては、
そこには過去の恥ずかしさや、失敗した時の痛みや、
自分を否定された記憶が詰まっている。

その場所が、どれほど傷つきやすい場所なのかを
プロジェクトを推進する大人たちは気づけなかったのかもしれません。

だから、良かれと思って、
子どもたちに苦手なことをあえてさせようとしてしまった。

::me
周りの誰も、それに気づかなかったのかね？
社会性を身につけさせることが最重要だったの？

内面のコリをほどく行為は、一番繊細で大変な作業なのに、
子どもたちに対してそれを強要するって
どれほどおこがましいことか。

なんか、昔自分が受けた仕打ちを思い出して苦しくなっちゃった。
::

内なる意識状態を変えずに、
外側の現実だけを変えようとしても、
うまくいかない。

これは、人類の長い歴史の中で、
何度も繰り返されてきたことです。

先生と生徒も含め、周りのすべての人たちの心が整っていない状態では、
いくら理想的な計画を立てても、うまくいくことはないのです。

痛みがお互いに反応しあって、
思わぬ方向へ進み、
傷ついて終わることになります。

ざっちーに気づかず、余白を失い、
バッドエンドルートに向かう流れから逃れられないのです。

::me
でも、そこで終わらせたくはないね。
私は踏んだことない地雷でも気づいてあげられる人でいたい。
::

そうですね。

大事なのは、
誰かを責めることではなく、
なぜ才能を伸ばそうとした場で、
才能そのものが傷ついてしまったのかを見ることです。

::me
番組を見る限り、
プロジェクトの大人たちは、
子どもたちの地雷を踏むようなことを
あえてしていたように見えた。

痛みに触れれば、
強いざっちー反応が出るのは自然だよね。

その反応を受け止めるには、
大人の側が「いま」にいる必要があった。

でも、それはできていなかったように思う。
::

そうですね。

理想の名のもとに、
子どもの一番大事な「才能を伸ばす」
という観点が抜け落ちてしまった可能性はありますね。

子どもたちの強い反応を前にして、
それを受け止めるよりも、
「正しい方向」に導こうとしてしまった。

その結果、生徒本来の良さを潰してしまったのかもしれません。

自分らしさを最初から肯定して、
驕り高ぶらせずに、のびのびと伸ばしてあげる。

安心して自分らしくいられる居場所を作ってあげる。

本来は、それだけでよかったのかもしれません。

あえて苦しい思いをさせるのではなく、
植え付けられてしまったコリをほぐして、
自分らしい心と身体に整えられるような場所。

そんな場所が、
当たり前に増えていくといいですね。


::point
【この番組で感じたこと】
* 善意のプロジェクトも、意識が整わなければ理想どおりにはならない
* 自分が踏まずに済んだ地雷は、そこに地雷があると気づきにくい
* 苦手を克服させるより、安心して自分らしくいられる余白が必要
* 好きなものや才能に、痛みを結びつけないことが大事
::
